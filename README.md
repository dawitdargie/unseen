# Unseen

Explore extraordinary places on Earth and fascinating discoveries beyond our planet.

This project primarily develops real-world backend engineering skills through guided implementation with Go, PostgreSQL, Docker, Kubernetes, and AWS. B01 is in progress: the Go module and first liveness endpoint exist; database and frontend integration follow.

Start with the [implementation and learning plan](docs/implementation_plan.md). It records the architecture decisions, teaching agreement, milestone order, and evidence required before advancing.

The [full learning roadmap](docs/learning_roadmap.md) separates every remaining milestone into individual lessons, from the current server through final handoff and separate Python practice.
